主要功能
  • 静默安装 Git Bash（官方 + standtrain 备用镜像自动测速）
  • 安装包内置 Claude 安装脚本并在执行前校验固定 SHA256
  • 下载文件必须通过大小、格式与 SHA256 校验
  • 写入 .claude.json 的 hasCompletedOnboarding
  • 安装位置搬迁到 %ProgramData%\claude、追加系统 PATH
  • 可选加装 CC Switch 供应商切换 GUI
安装来源
  • Claude Code 发布文件 · Anthropic 官方存储
  • Git for Windows · 官方 Release 与固定校验值
